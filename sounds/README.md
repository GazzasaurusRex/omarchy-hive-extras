# Optional event sounds

These cues are intentionally short and quiet. They are not wired to ordinary
desktop actions and are disabled by default.

- `access-confirm.wav` — two-note terminal acknowledgement
- `access-denied.wav` — low, subdued denial cue
- `security-alert.wav` — restrained double alert

Preview with `pw-play sounds/access-confirm.wav`. If you later attach them to
events, prefer rare explicit events such as a manual security test; do not bind
them to clicks, window focus, typing, or recurring notifications.
